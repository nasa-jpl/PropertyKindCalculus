    structure PropertyKindCalculus.Uncertainty.MomentData (R : Type) :
    Type

    Carrier-parametric moment/cumulant data for an input quantity. variance is κ₂ = u²; fourthCumulant is κ₄ = w (Willink Table 1), zero for a normal; thirdCumulant is κ₃ (asymmetry, zero for the symmetric families). Consumed by the linearized methods and proved about over ℝ.

    • mean : R

      Expected value E(Xᵢ).

    • variance : R

      Variance u² (the second cumulant κ₂).

    • fourthCumulant : R

      Fourth cumulant w (κ₄); 0 for a normal distribution.

    • thirdCumulant : R

      Third cumulant κ₃ (asymmetry); 0 for symmetric distributions. (No default: R is an unconstrained carrier, so there is no generic 0 to default to — set it at each site.)

      structure PropertyKindCalculus.Uncertainty.InputDist (R : Type) :
      Type

      The input uncertainty descriptor. Carrier-parametric moments, an optional rigorous support (for the numerical-adequacy check), and an invCDF sampler shared by MCM and SSPRC.

      • moments : MomentData R

        The carrier-parametric moments/cumulants.

      • support : Option (R × R)

        Rigorous support [lo, hi], when the distribution is bounded (feeds numerical adequacy).

      • invCDF : Float → Float

        Inverse CDF: maps a probability p ∈ (0,1) to a sample. Random p ⇒ MCM; systematic p = (j-0.5)/N ⇒ SSPRC. Concrete Float: sampling yields concrete numbers.
