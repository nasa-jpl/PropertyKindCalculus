    def PropertyKindCalculus.KindOfProperty.BearsUnit (k : KindOfProperty) :
    Prop

    §13.3.3 — a kind bears a metrological unit (is a unitary kind-of-quantity) iff its scale is at least differential: its magnitudes are "a reference quantity multiplied by a number" (§13.3.4 differential, §13.3.5 rational). Ordinal and nominal kinds do not bear a unit (Dybkær §9.13.4).

      structure PropertyKindCalculus.MetrologicalUnit :
      Type

      §18.12 metrological unit — one quantity of a kind chosen as the reference, "with which any other quantity of the same kind can be compared". Carried as the kind it references together with its terminological symbol (the §18.12 unit id, e.g. "m", "kg"). Like KindOfProperty, it is an open value so applications declare units as defs.

      • kind : KindOfProperty

        §18.12 / §13.3.3 — the kind whose quantities this unit references. A well-formed unit's kind must bear a unit (WellFormed).

      • symbol : String

        §18.12 — the terminological identity of the unit (the unit id, e.g. "m").

              def PropertyKindCalculus.MetrologicalUnit.Commensurable (u₁ u₂ : MetrologicalUnit) :
              Prop

              §9.13.4 "of the same kind" — two units are commensurable iff they reference the same kind. This is the only relation along which a value converts: a metre and a centimetre are commensurable (both length); a metre and a kilogram are not — and that is a fact of the types, not a runtime guard.

              Equations
              • u₁.Commensurable u₂ = (u₁.kind = u₂.kind)
