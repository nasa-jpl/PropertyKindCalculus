    The AVS kinds-of-property (the opt-in registry) #

    Read off σ⁰ = a·ndvi + exp(−2·b·ndvi)·c·r + d: b·ndvi sits in exp ⇒ b : ndvi⁻¹; a·ndvi is a backscatter ⇒ a : σ⁰·ndvi⁻¹; c·r is a backscatter ⇒ c : σ⁰·reflectivity⁻¹; d : σ⁰. All ratio-scale (so the kind arithmetic is defined) and all dimension one (a dimension checker cannot separate the three roles below — only the kind check can).
