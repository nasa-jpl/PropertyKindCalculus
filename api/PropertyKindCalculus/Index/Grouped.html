    The grouped kind view — kinds read through the boundaries that carry them #

    The kinds census is alphabetical: the lookup surface, and the denominator every partition claim is checked against. It answers "what is this kind?" and not "where does it enter?". The tables here answer the second question from the same environment, by joining the census to the declared Provenance.Contracts: a port states its kind by declaration name (KindRef.decl), so every kind a boundary carries is a row of this join, with the boundary and the port's role.

    The join is restricted to the census: a contract in scope may state a kind declared outside it (a shared upstream kind, a kind of another layer), and such a port binds nothing here — the rows of every table below are census kinds, which is what lets the grouped view and the absences partition the census exactly. A document wanting the external kinds reads the contracts table, where the interface is rendered whole.

    Three readings, one join:

    • kinds-by-boundary — the grouped reading: boundary, then role (in the module card's reading order: inputs, parameters, configuration, outputs), then kind. A document that partitions its boundaries into subsystems passes the partition as named scopes and gets a leading Subsystem column; the assignment is the document's, the rows are the environment's.
    • kinds-in-context — the census with two context columns: which boundaries carry the kind and in which roles. Same rows, same order as kinds, so it can replace the census in a document without disturbing what the census pins.
    • kinds-unbound — the census kinds no declared boundary carries. Rendered as a table of absences, like provenance-coverage: its row count is the partition's remainder, and #pkc_kinds_partition states the whole claim — census = bound + unbound — as one line a probe can pin.

    Like the contracts table, @[kindCounterexample]-tagged contracts are not sources: a deliberate misdeclaration binds no kind.

            def PropertyKindCalculus.Index.kindBindings (layer : KindLayer) (scope : Scope) :
            Lean.MetaM (Array KindBinding)

            Every (boundary, port, kind) binding declared in scope whose kind is in layer's census in scope — the join the three tables and the partition read. A port kind outside the census (declared elsewhere, or of another layer) binds nothing. Counterexample contracts are excluded, as in the contracts table. A kind a signature states more than once (k → k) is one binding of that port, not two.
