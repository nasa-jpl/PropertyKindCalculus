    structure PropertyKindCalculus.AuditReceipt :
    Type

    One run of an audit command.

    • audit : String

      The audit's identity — the command's name without its #, e.g. kind_boundary_clean. This is the string a rubric's Closure names in audits.

    • scope : Array Lean.Name

      The namespaces the run walked, as the author spelled them.

    • module : Lean.Name

      The module the command ran in.

              def PropertyKindCalculus.AuditReceipt.covers (r : AuditReceipt) (ns : Option Lean.Name) :
              Bool

              Does a run cover a document's declaration scope? A run over ns covers every scope under it: the audit walked SoilMoisture, so it walked SoilMoisture.Algorithm. The reverse is not coverage — a run over a sub-namespace says nothing about the rest — which is the direction a conformance check must refuse. A document with no scope accepts any run of the audit, which is right only when its environment contains no other document's.

              Equations
              • r.covers none = true
              • r.covers (some n) = r.scope.any fun (s : Lean.Name) => s.isPrefixOf n
