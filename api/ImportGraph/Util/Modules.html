      source
      @[inline]
      def ImportGraph.System.FilePath.modules (dir : System.FilePath) (root : Lean.Name := Lean.Name.anonymous) :
      Modules

      Allows iteration over the modules (any *.lean file) under dir via for (mod, dirEntry) in dir.modules do, descending into subdirectories (top-down, left-to-right), and constructing the module name according to the directory names and *.lean filenames.

      For example, if dir contains A/B/C.lean, this iteration visits (A.B.C, ⟨"A/B", "C.lean"⟩).

      If root is provided, then root is prepended to the module names created from paths in the directory, e.g. if dir contains A/B/C.lean and we iterate through for (mod, dirEntry) in dir.modules (root := `Foo), this iteration visits (Foo.A.B.C, ⟨"A/B", "C.lean"⟩).

      By default, no root is inferred.

      Equations
      • ImportGraph.System.FilePath.modules dir root = { dir := dir, root := root }

        def ImportGraph.System.FilePath.toDirEntry (path : System.FilePath) :
        IO.FS.DirEntry

        Splits path into the DirEntry for its enclosing directory and file name, as readDir would report it. path.parent (rather than path.withFileName "") is used for root so that it carries no trailing separator and so that root / fileName round-trips back to path (matching the entries produced when iterating through a directory).
