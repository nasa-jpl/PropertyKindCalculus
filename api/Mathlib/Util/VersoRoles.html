    Verso docstring roles #

    This module provides custom Verso docstring roles and code blocks used to support Verso syntax in Mathlib docstrings:

    • {url} turns a code literal containing a URL into a link.

    • {library_note} references a library note and checks that it exists.

    • {cite} references a bibliography entry and renders custom text for it.

    • The code code block records a verbatim code listing in the given language.

    The roles are declared in the root namespace so that they are available in every docstring without opening a namespace.

                  A reference to a library note.

                  The code literal contains the note's label, as in {library_note}`partially-applied ext lemmas`. A warning is reported when no library note with this label is in scope, so that references to notes defined later are allowed. Set the option doc.verso.libraryNote.warnOnMissing to false to disable this warning.
