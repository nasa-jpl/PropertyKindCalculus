    Self-inverse elements #

    This file defines self-inverse elements of a type with an inversion, i.e. elements a satisfying a⁻¹ = a.

    Main declarations #

    • IsSelfInv a: The element a satisfies a⁻¹ = a.
    • IsSelfNeg a: The element a satisfies -a = a.
