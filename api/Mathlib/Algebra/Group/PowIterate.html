    Powers on monoid of functions #

    If F is a type of functions from α onto itself equipped with a monoid structure such that 1 is the identity and multiplication is given by composition, then natural exponentiation corresponds to iteration of composition.

    This is separated from the Mathlib.Algebra.Group.IsApply file to avoid importing Monoid there.
